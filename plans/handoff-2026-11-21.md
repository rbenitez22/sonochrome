## Loose ends
- **Large colour images may draw blank on iPhone and iPad.**
  - **Cause:** Safari limits a canvas to about 16.7 million pixels (4096 × 4096). The Colour view only caps each side, at 16,000 px (`MAX_CANVAS` in `public/src/app/color/canvas.js`). So, for example, 300×300 cells at 20 px (6,000 × 6,000 = 36M pixels) most likely comes out blank, with no error. Desktop browsers are fine.
  - **Fix:** also cap the area, by lowering the pixels per cell until `w·h·eff² ≤ ~16M`. Better still, show the image fitted to the box with CSS scaling, and use the pixel size only for the PNG.
  - **Size limit kept:** the user chose to keep the 300×300-cell limit for now (2026-11-21). Going to 1000×1000 would need ImageData drawing and typed-array cells.
- **A leftover Cloudflare Pages project `chromatone`** (chromatone-4cq.pages.dev) holds one preview deployment. Delete it, if wanted, with `npx wrangler@4.166.0 pages project delete chromatone`.
- **pi-notes** (`/programming/pi-notes`, local only by the user's choice): branch `musicxml-download` has 3 commits that are on no other branch (MusicXML download, the pinned-codes fix, the colour prototype). It was branched from `plans/portfolio-video`, which isn't on `master` either.
