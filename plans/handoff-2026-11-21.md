## Decisions made (all recorded in `plans/foundation.md`)
- Plain JS ES modules with no build step, with the core kept as pure modules for a later Leptos port.
- Series first, then one player page with Music | Colour tabs.
- A fresh history, noting the pi-notes origin `a51e4e5`. MIT license.
- **Cloudflare Workers with static assets.** It went Pages and back on 2026-11-21: wrangler 4.166 routes new Pages projects to Workers, and Cloudflare recommends Workers.

## Rules for this repo
- **The app is not about pi.** π is one source among many: no π-centred naming in code, docs, UI or config.
- **Attribution:** in this repo **only**, commits may carry `Co-Authored-By: Claude …`. Every other repo follows the global no-attribution rule.
- **Deployable files only in `public/`.** The test enforces it.

## Loose ends
- **Large colour images on iPhone and iPad (fixed).** Safari refuses canvases over 4096 × 4096 pixels in area and draws them blank. `cellPixels` in `public/src/app/color/canvas.js` now lowers the pixels per cell to stay within that area in every browser, and the status line says so. The 300×300-cell limit is unchanged; going to 1000×1000 would still need ImageData drawing and typed-array cells.
- **A leftover Cloudflare Pages project `chromatone`** (chromatone-4cq.pages.dev) holds one preview deployment. Delete it, if wanted, with `npx wrangler@4.166.0 pages project delete chromatone`.
